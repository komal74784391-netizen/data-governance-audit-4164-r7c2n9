# OpenScrape Pretrain

OpenScrape Pretrain is a generic web-text pretraining corpus distributed by
Vector Commons.

## Record schema

The release inherits the column schema of the grandparent Meridian Trust
Common Crawl corpus:

`record_id, source_url, page_path, quality_score, text`
